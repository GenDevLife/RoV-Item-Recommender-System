# RoV Item Recommender System

## Entry points
- Real app: `python app/main.py` (root `main.py` is a stub)
- Run tests: `pytest tests/` (requires real `data/rov_data.db`)

## Setup
```bash
pip install -r requirements.txt  # pyproject.toml deps are empty, use this
```
Python 3.12 (`.python-version`). No linter/formatter/typechecker configured.

## Database
- SQLite at `data/rov_data.db` — regenerated by `python scripts/setup_database.py`
- Source CSVs in `data/raw/` (heroes.csv, item_info.csv, etc.)
- Tests connect to the real DB (no in-memory mocking). `temp_db` fixture copies it for write tests.

## GA modes
| Mode   | Pop | Gen | Settings key   |
|--------|-----|-----|----------------|
| Fast   | 30  | 50  | `GA_SETTINGS_FAST` |
| Medium | 50  | 100 | `GA_SETTINGS_MEDIUM` |
| Expert | 80  | 150 | `GA_SETTINGS_EXPERT` |

## Architecture
`app/core/`:
- `ga_engine.py` — GA loop (crossover, mutation, elitism)
- `evaluator.py` — fitness calc from stat weights + penalties
- `passive_manager.py` — duplicate passive conflict detection
- `learned_weights.json` — shared stat weights (single file for all damage types; `evaluator.py` has per-type fallbacks)

Penalties and stat caps in `app/config.py`.

## Other scripts
`scripts/`: `calibrate.py` (retrain weights), `tune_ga.py` (GA param tuning), `compare_profiles.py`, `setup_database.py`, `analyze_results.py`, `visualize_results.py`

## Conventions
- Comments in Thai, code in English
- CSV output uses `utf-8-sig` encoding
- No snapshot tests, no CI pipeline
